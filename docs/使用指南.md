# DisCraft 使用指南（Forge 1.20.1 預覽版）

實際交付檔名、commit、SHA256、大小與 CI 會列在交付版指南開頭。
這是可安裝的預覽 build，並非 GitHub Release 或已部署的伺服器。

## 1. 安裝

需要 Minecraft **1.20.1**、Forge **47.4.0**、**Java 17**。
將交付的 `DisCraft-0.2.0-preview.3.jar` 放進專用伺服器的 `mods/`，
更新時移除舊 DisCraft JAR，避免重複 mod ID；不需要另外安裝 core JAR。

DisCraft **不強制綁 client**。未安裝 DisCraft 的 Forge 玩家仍可加入，
使用伺服器聊天橋接、事件通知及 `%item`／`%i`。需要圖片、picker、剪貼簿等
增強時，再把同一 build 放入玩家 Minecraft instance 的 `mods/`。
建議 server／client 使用同版；已安裝但協定不相容的 DisCraft 會拒絕連線，
目前協定是 **4**。Client 有裝、server 沒裝時，普通遊戲仍可使用，Discord
橋接不會啟用；本機 Twemoji 顯示不需要新帳號或 API key。

這只表示 **DisCraft** optional，不代表其他內容 mod 可以不裝。
尚未驗證純 vanilla 執行檔、任意大型模組包或真實線上登入簽章的完整端到端流程。
正式 Discord adapter 僅在啟用帳號驗證的專用伺服器啟用，請保留
`server.properties` 的 `online-mode=true`；不要使用測試 JVM flags。

## 2. 第一次設定：自動建立停用範本

專用伺服器啟動時，若新、舊設定檔都不存在，會自動建立有註解的 UTF-8 安全範本。
**預設停用、token／channel 空白，完全不從環境變數填入憑證**。
不需要先啟用 Discord；client 或單機整合伺服器不建立這份 server 設定，也不連 Discord。
產生位置：

```text
<伺服器目錄>/config/discraft/server.properties
```

以下是自動範本的安全預設；預設不連 Discord、不發事件。停止伺服器後再編輯：

```properties
enabled=false
channel=
botToken=
allowedPlayers=
locale=en_us
resourcePacks=
notifications=
itemDisplay=false
```

只有這八個欄位受支援，整份設定上限 8 KiB。
在**伺服器本機**填入自己的 Bot token 與普通 guild 文字頻道 ID：

- `botToken`：只填 token 本身，不加 `Bot `、引號或空白。不要放入 client、
  JAR、聊天、截圖、Git 或啟動參數；本指南與交付 JAR 不含現有 token。
- `channel`：數字 Channel ID，不是 `#名稱`、邀請連結、DM、thread 或 voice channel。
- `allowedPlayers`：Minecraft 帳號驗證 UUID，逗號分隔；留空拒絕所有玩家，
  `*` 允許所有伺服器玩家。這裡不是 Discord ID，也不是玩家名稱。
- `enabled=true`：完成本機設定後才開啟，這是唯一的 Discord 連線開關，**不需要額外 JVM flag**。
- `locale`：範本預設 `en_us`；繁中可改成 `zh_tw`，簡中可改成 `zh_cn`。

正常使用 Forge 的 `run.sh`／`run.bat` 重新啟動即可。舊的
`-Ddiscraft.discord.enabled=true`／`false` 都已不再生效，可移除該行。
**升級後想保持停用，請在 config 設 `enabled=false`，不能再靠舊 flag=false 阻止連線。**
正式 token／channel
**只讀 config**，不會從 `discord_token`、`discord_channel` 或其他環境變數補值。
無法建立、錯誤格式、未授權玩家或未啟用時不會取得橋接能力。
自動建立先完整寫入空憑證暫存檔，再以不可覆寫的硬連結發佈；並行啟動不會讀到半份範本。
若檔案系統不支援這種安全建立方式，或沒有寫入權限，會記錄不含秘密與完整路徑的提示並停用；
可在停服後手動放入 repository 的空白 example。程式不會覆寫或修補任何既有設定。
修改 config／匯入包後需要重新啟動 server；不是執行 `/reload`。

### 舊路徑相容與 client 檔案

所有 DisCraft 設定與本機匯入資料集中在 `config/discraft/`：
`server.properties`、`resourcepacks/`，以及 client 手動選檔的 `uploads/`。
目前沒有額外的持久 client 設定檔；Minecraft 原生截圖仍在 `screenshots/`，
剪貼簿 helper 使用作業系統暫存，不會把暫存執行檔寫進 config。

升級時，各項**獨立**採新路徑優先：

| 新路徑 | 僅新路徑不存在時讀取的舊路徑 |
| --- | --- |
| `config/discraft/server.properties` | `config/discraft-server.properties` |
| `config/discraft/resourcepacks/` | `config/discraft-resourcepacks/` |
| `config/discraft/uploads/` | instance 根目錄的 `discraft-uploads/` |

使用或忽略舊路徑時有不含秘密的警告，不會搬移、合併、覆寫或刪除檔案。
缺新設定但已有舊設定時不建立新預設，避免把舊 token／選項遮住；舊設定無效也保留原檔並停用。
新設定即使停用、留空或無效，也不會改讀舊 token；無效資料會安全拒絕。
新資源目錄即使是空的，也不會逐檔混入舊目錄的 ZIP。符號連結與無效父目錄拒絕。
若要手動遷移，停止遊戲／server，自行備份後把完整設定或 ZIP 複製到新位置；
保留原本檔案，確認新設定啟動成功後再由你自行處置。

## 3. Discord Bot 準備

使用自己的官方 Bot application，讓 Bot 在指定 guild／文字頻道內具備：
**View Channel、Read Message History、Send Messages、Attach Files**。
為讀取一般成員文字與附件，需在 Developer Portal 的 Bot 設定確認
**Message Content Intent**；受審核限制的 application 需依 Discord 規則處理。
本 mod 不會替你建立／輪換 token、開啟 flags、變更角色或要求 Administrator。

使用官方 bot 帳號，不要使用個人 user token。只支援一個指定的普通 guild
文字頻道，採 REST 輪詢；沒有 Gateway resume、DM／thread、編輯／刪除同步、
反應、語音或個人 Discord 收藏同步。有效能力仍以你自己的 server 實測為準。

## 4. 開啟物品、事件與語系

完成憑證後，依需求修改，例如：

```properties
enabled=true
channel=請在本機填入數字頻道ID
botToken=請在本機填入自己的token
allowedPlayers=*
locale=zh_tw
resourcePacks=CTE2-2.1.4-Chinese-Language-Only-CN-TW.zip,my-overrides.zip
notifications=join,quit,death,advancement,lifecycle
itemDisplay=true
```

上面 `channel`／`botToken` 的說明字串**不是可用值**，不可原樣啟動。
不使用的外部 ZIP 請從清單移除；也可完全留空。

`notifications` 可填 `join,quit,death,advancement,lifecycle` 的子集合；留空不發
自動事件。加入／退出、死亡與進度只對允許的玩家生效。死亡保留人名、實體及
物品語意，取消／被救回的死亡不誤報；進度需完成且有可公告 display，遵循
`announceAdvancements` 與公告設定，排除 recipe／隱藏進度，避免 criterion 重複。
原版遊戲內進度公告保留，不額外重播一次。

`lifecycle` 會嘗試通知啟動中、啟動完成、正常關閉，關閉有有界排空。
**斷電／崩潰不能保證送出關閉訊息**，啟動失敗也不會誤報已就緒。

## 5. 材質包／漢化包放哪裡？

建立以下目錄，把 ZIP 原檔放入，**不用解壓**：

```text
<伺服器目錄>/
  mods/
    DisCraft-0.2.0-preview.3.jar
  config/
    discraft/
      server.properties
      resourcepacks/
        CTE2-2.1.4-Chinese-Language-Only-CN-TW.zip
        my-overrides.zip
```

在 `resourcePacks` 僅填檔名，逗號分隔，**由低到高排列，後者覆蓋前者**。
不接受網址、絕對路徑或任意子目錄。上面的 CTE2 名稱只是你已有檔案的示例，
不會隨 JAR 再打包／散布，也不會替你下載或安裝整個模組包。

語系順序：先以已安裝 mod 提供的所選語系作基底，再讓各 ZIP 逐 key 覆蓋；
缺少 key 才找合併後 `en_us`、Forge 原有英文、explicit fallback／key。
`zh_tw` 和 `zh_cn` 獨立選擇，不互相偷換；mod 自己寫死的 literal 不能假裝翻譯。
包內自動繁中內容的品質仍以原作者提供的資料為準。

使用 **Minecraft 1.20.1 resource pack format 15**。目前限制：最多 8 ZIP、
合計 20,000 entries／128 MiB 解壓量、單 entry 4 MiB、保留資源 64 MiB、
每 ZIP 壓縮大小 64 MiB；JSON 另有大小／深度限制，圖片與字型亦有像素／快取界限。
路徑穿越、symlink、錯誤格式與超限包會被拒絕，不會執行包內內容。

語言檔按 key 合併；模型／紋理／字型 JSON 以整檔覆蓋。
Discord 目前主要輸出 **tooltip 文字圖**，沒有固定大模型主圖；匯入語言與
受支援 bitmap／space／reference 字型可改善文字。保留的 headless 模型解析器
並不等同 Minecraft client，不能宣稱支援所有 Forge custom loader／BEWLR／
GeckoLib 或任意材質包。這份 server 匯入清單不會自動把資源包安裝到玩家 client。

## 6. 聊天與展示物品

Minecraft → Discord 的文字例如：

```text
<Aitchn> 你好
```

Discord 發送帳號仍是 Bot，玩家名是文字前綴，不會改 Bot 名稱或建立 webhook。

Discord → Minecraft 顯示 `[D] 成員顯示名稱: 文字`；採 guild nickname／適用的
顯示名稱 fallback，不固定成 Bridge 或測試名字。

`itemDisplay=true` 時，在聊天輸入：

```text
看看我的 %item
看看我的 %i
%i / %item
看看%i吧
```

兩者完全相同，都由 server 一次複製**當下主手**，不是相信 client 的物品內容。
一則最多八個有效標記，混用也共用八個額度／一張 Discord PNG；空手安全顯示文字。
`%inventory`、`%itemized`、`%i_`、`%i9` 不展開；只定義小寫 token。
已選取 mention 範圍內的標記維持 literal，產生的物品名不再遞迴展開。
不能同則混用上傳附件與物品圖卡；過長輸出會被拒絕。

Minecraft 中是有樣式的 inline 物品名稱，滑過顯示原生詳細 tooltip，**不開新畫面**。
進度名稱／框架顏色依原版與樣式，不固定綠色。
Discord 同一則訊息附內容自適應的黑紫 Minecraft tooltip PNG，顯示安全的名稱、
附魔、lore、屬性與適用耐久；遵循 HideFlags，損壞耐久採已說明的 advanced-style
行，並非宣稱 Discord 支援任意文字 hover。不外送容器內容、書頁或完整 NBT。

普通 native chat 不會為橋接而重發一份遊戲訊息。被取消、遮蔽、無法安全對應的
改寫／filter 會保守停止轉送原文。後續 listener 替換 presentation root 也會
fail closed；原生顯示仍照常。SYSTEM／Commands Only 發送者可由真實收件者確認；
若完全沒有原生收件者，保守不製造一次假的 broadcast。未知送達結果不自動重送。

## 7. 有／沒有 client mod 的差異

| 功能 | Server 有、client 無 DisCraft | Server＋client 同版 DisCraft |
| --- | --- | --- |
| 普通聊天與設定啟用的事件 | 有 | 有 |
| `%i`／`%item` 主手與原生 hover | 有 | 有 |
| Discord 文字來源 `[D]` | 原生 component | 原生 component＋增強 |
| Unicode emoji | client 原有字型 | 固定 Twemoji 圖像 |
| Guild 自訂／動畫 emoji | `:name:` 文字 fallback | 可搜尋 picker／有界預覽與動畫 |
| 圖片／GIF 附件 | client-required 文字 | 可顯示有界圖片／動畫 |
| 點作者選取穩定 D@／M@ mention | 無專屬選取 | 有；手打同名不自動取得 ping 身分 |
| 圖片剪貼簿／F2／spoiler 卡片 | 無增強 | 有；不會自動發送 |

增強 UI 保留原生 **T 聊天**；笑臉開 picker，**F8** 是明確 bridge 快捷方式。
**Ctrl+V** 有圖片像素時先暫存圖片，普通文字貼上照原生處理；**F2** 可複製截圖
像素並保留完整原始截圖檔。暴雷／移除只操作待送卡片；收到的 spoiler 要明確揭露。
上傳圖片每邊最多 1024 pixels、每檔 256 KiB、每訊息一個附件；支援 PNG／JPEG／GIF。
Linux X11 已做實測，Windows／macOS／Wayland 剪貼簿尚未驗證。

Twemoji 固定 **17.0.3**，不是宣稱與 Discord 當前 exact version 同步。
支持完整已索引序列、膚色、ZWJ、旗幟、keycap 與 VS 選擇；未知 cluster 保留文字。
英文 Unicode 名稱與完整序列可搜尋。點選會插入真正原生輸入框的游標／選取範圍，
收起 picker 並恢復原生輸入焦點，不會自動送出；搜尋欄或其他 mod 的 EditBox 順序不決定插入目標。圖像屬 Twitter, Inc. 與其他貢獻者，
CC BY 4.0；來源、MIT／Unicode license 與修改說明已隨 JAR 放在 `twemoji/`。
PNG bytes 未修改，僅索引及依介面尺寸繪製。

**GIF 遠端服務／貼圖來源尚未啟用**。不會私用 Discord endpoint、同步私人收藏、
要求新 key 或冒用個人帳號。明確 TEST 模式／標題畫面的本機 demo 不是正式 provider。

## 8. 檢查與停用

若橋接無反應，依序確認：同版 Forge／Java、專用伺服器且 online-mode=true、
config 路徑／UTF-8／八個合法欄位、`enabled=true`、允許玩家 UUID、指定文字頻道、
Bot 權限與 Message Content，以及匯入 ZIP 格式／限額。不要把 token 貼回聊天室。
需要停用時把 `enabled=false` 並重啟。

CI 使用隔離 Forge 世界與 localhost 收件端，包含無 mod／有 mod／不相容協定、
重連、取消／遮蔽、同文多收件者競態、native UI／hover／作者點選與字型／資產快取。
這些通過不等於任意模組包、所有聊天 mod、純 vanilla 或真實 online auth 都已驗證。

官方設定參考：[Discord permissions](https://docs.discord.com/developers/topics/permissions)、
[Message Content Intent／HTTP 限制](https://docs.discord.com/developers/events/gateway#message-content-intent)、
[Twemoji 17.0.3 原始來源與授權](https://github.com/jdecked/twemoji/tree/v17.0.3)。


## 9. 啟動了卻沒有反應：先看安全狀態

新版本會記錄 `DisCraft loaded` 與 logical server 的 `state=`，並只列出固定相對
config 來源；不列 token、HTTP header／body、URL／query、頻道／成員 ID 或聊天內容。
舊 preview.2 的「沒有錯誤」不能證明 Discord 已連線，也不能僅憑 Java／Forge 版本差異判定原因。

| 狀態／代碼 | 意義與下一步 |
| --- | --- |
| `DISABLED_CONFIG` | 選中的 config 是 `enabled=false`。確認記錄的新／舊相對來源，停服後編輯正確檔案。 |
| `DISABLED_OFFLINE`／`DISABLED_INTEGRATED` | authenticated dedicated 邊界未符合；不會偷偷改 server 設定。 |
| `CONFIG_INIT_FAILED`／`CONFIG_LOAD_FAILED` | 檔案無法安全建立／讀取或內容無效；不輸出原始例外與秘密。 |
| `RESOURCES_FAILED`／`ADAPTER_FAILED` | 本機資源或 adapter 建立失敗，橋接停用。 |
| `CONNECTING_UNVERIFIED` | config 已啟用並建立 REST adapter，**尚未證明** bot／頻道／讀取／傳送成功。 |
| `players=DENY_ALL` | allowlist 留空，所有玩家橋接都被拒絕；不列玩家 UUID。 |
| `lifecycle-notices=false` | 沒開啟 server 啟停通知，沒有啟動貼文不代表 API 已失敗。 |
| `TARGET_VERIFIED` | 實際回應已驗證 bot 身分與普通 guild 文字頻道，尚不表示可讀／可傳。 |
| `READ_READY` | 實際讀到有效訊息頁；不代表已收到真人測試訊息或 client 已渲染。 |
| `SEND_ACCEPTED` | 實際收到有效傳送 receipt；不列出 message ID 或內容。 |
| `AUTH_REJECTED` HTTP 401／`PERMISSION_REJECTED` HTTP 403 | `terminal=YES`，保持停止，操作員修正設定／權限後重新啟動；不自動重試。 |
| `NOT_FOUND` HTTP 404 | 目標資源不存在或不可存取，依 `operation` 檢查頻道／成員等範圍；保留既有有界讀取 backoff，不新增訊息重送。 |
| `RATE_LIMITED` HTTP 429 | 沿用共用 retry_after 門檻；不提前重試或重送訊息。 |
| `NETWORK_FAILED`／`TIMEOUT` | 網路／HTTP stream 或既有截止時間失敗；不列原始端點、DNS、憑證與例外文字。 |
| `INVALID_RESPONSE`／`OPERATION_FAILED`／`QUEUE_FULL` | 回應驗證、操作或有界佇列失敗；拒絕或送達未定時不自動重送。 |

背景同類訊息每分鐘去重、全域限量且快取有界；首次 terminal 原因仍會記錄。
`TEST bridge` 只代表 localhost mock，不能當成真 Discord API 成功。Bot 在線狀態也不能
代替雙向功能驗證。若仍無反應，只提供上述狀態附近已去除秘密的紀錄，不要貼 token 或整份 config。
